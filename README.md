# 🌍 Atlas

> The community-driven interactive map platform for open-world games.


---

## 📖 About

Atlas is an interactive community platform designed for open-world games.

Unlike traditional interactive maps, Atlas allows players to **discover, document and validate** locations together.

The project starts with **Grand Theft Auto VI**, but has been designed from day one to support multiple games in the future.

Our vision is simple:

> **Build the Wikipedia of exploration for open-world games.**

---

## ✨ Core Features

### 🌎 Community Map

- Interactive map
- Community discoveries
- Screenshots
- Categories
- Comments
- Community validation
- Discovery history

---

### 👤 Personal Map

Every player has their own private map.

Features include:

- Personal markers
- Notes
- Progress tracking
- Exploration percentage
- To-do locations

---

### 🏆 Player Progression

Contributing to the community rewards players with:

- XP
- Levels
- Badges
- Reputation
- Global leaderboard

# Product Vision

## Overview

Atlas is a community-driven interactive map platform designed for open-world games.

Unlike traditional interactive maps, Atlas combines exploration, community contributions and player progression into a single experience.

The project initially focuses on Grand Theft Auto VI but has been designed to support multiple games in the future.

---

# Mission

Our mission is to create the most complete and reliable exploration platform for open-world games.

Players should not only use Atlas to search for locations but also contribute to building the world's largest community knowledge base.

---

# Core Pillars

Atlas is built around three fundamental pillars.

## 1. Community Map

Players can:

- Discover new locations
- Upload screenshots
- Share discoveries
- Vote discoveries
- Improve existing information

---

## 2. Personal Map

Each player owns a private map.

Players can:

- Track explored areas
- Create personal markers
- Save notes
- Build exploration routes
- Follow completion progress

---

## 3. Player Progression

Players earn rewards by helping the community.

Progression includes:

- Experience
- Levels
- Reputation
- Badges
- Leaderboards

---

# Long-Term Vision

Atlas is not a GTA VI website.

Atlas is an exploration platform.

Future games may include:

- GTA VI
- Red Dead Redemption
- The Elder Scrolls
- The Witcher
- Cyberpunk
- Minecraft

---

# Design Philosophy

Every feature must reinforce at least one of these actions:

- Discover
- Explore
- Contribute

If a feature does not improve one of these pillars, it does not belong in the MVP.

---

# MVP Goals

The first public version focuses on:

- Community Map
- Personal Map
- Reputation System

Everything else will be developed afterwards.
